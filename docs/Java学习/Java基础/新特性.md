# 新特性

## 概述

> 汇总 Java 17 与 Java 21(LTS)最值得用的新特性:文本块、record、sealed、模式匹配、switch 表达式、var、虚拟线程等。这些特性能显著减少样板代码,提升可读性与并发能力,建议新项目直接采用。

## 核心知识点

### 文本块(Java 15 正式)

三引号 `"""` 定义多行字符串,自动处理缩进,避免 `\n` 拼接:

```java
String json = """
    {
      "name": "张三",
      "age": 20
    }
    """;
```

### record(Java 16 正式)

不可变数据类,自动生成构造器、`equals`/`hashCode`/`toString`:

```java
public record Point(int x, int y) {}
Point p = new Point(1, 2);
int x = p.x();   // 访问器,不是 getX()
```

适合 DTO、返回对象等纯数据载体。

### sealed 类(Java 17 正式)

用 `sealed`/`permits` 限定子类范围,配合模式匹配实现**穷尽性**检查:

```java
public sealed interface Shape permits Circle, Square {}
public record Circle(double r) implements Shape {}
public record Square(double side) implements Shape {}
```

### switch 表达式 + 模式匹配(Java 14 / 21)

```java
// switch 表达式:箭头语法,可直接返回值
int days = switch (month) {
    case 1, 3, 5, 7, 8, 10, 12 -> 31;
    case 2 -> 28;
    default -> 30;
};

// 模式匹配 for instanceof(Java 16 正式)
if (obj instanceof String s && !s.isEmpty()) {
    System.out.println(s.toUpperCase());   // 直接拿到 s,无需强转
}

// 模式匹配 for switch(Java 21 正式)
String desc = switch (shape) {
    case Circle c -> "圆,半径 " + c.r();
    case Square s -> "方,边长 " + s.side();
    // sealed 保证穷尽,无需 default
};
```

### var(Java 10)

局部变量类型推断,类型由编译器推导:

```java
var list = new ArrayList<String>();   // 类型是 ArrayList<String>
var map = Map.of("a", 1);             // 不可变 Map
```

**仅限局部变量**,字段/参数/返回值不能用。

### 虚拟线程(Java 21 正式,Project Loom)

「有栈协程」,几百万个轻量级线程随开随用,IO 密集场景吞吐量暴增:

```java
// 传统平台线程:1 个线程 ≈ 1MB 栈,开多了撑不住
Thread.ofPlatform().start(() -> doIo());

// 虚拟线程:极廉价,适合大量并发 IO
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    for (int i = 0; i < 100_000; i++) {
        executor.submit(() -> callRemoteApi());
    }
}
```

虚拟线程在 IO 阻塞时自动让出载体线程,不需要改代码即可获得高并发能力。

### 其他实用特性

- **Helpful NPE**(Java 14):NPE 信息会指明「哪个引用为 null」
- **`Stream.toList()`**(Java 16):比 `collect(Collectors.toList())` 简洁,返回不可变列表
- **`String.formatted()`**(Java 15):`"hi %s".formatted(name)` 替代 `String.format`
- **有序集合接口 `SequencedCollection`**(Java 21):统一 List/Deque 等「有顺序」集合,提供 `getFirst`/`getLast`/`reversed`

## 示例

```java
public class NewFeaturesDemo {
    sealed interface Result permits Success, Failure {}
    record Success(Object data) implements Result {}
    record Failure(String msg) implements Result {}

    static String handle(Result r) {
        return switch (r) {
            case Success s -> "成功: " + s.data();
            case Failure f -> "失败: " + f.msg();
        };
    }

    public static void main(String[] args) {
        System.out.println(handle(new Success(42)));
        System.out.println(handle(new Failure("超时")));
    }
}
```

## 常见问题与坑

- **`var` 别滥用**:复杂表达式的类型一眼看不出时,显式写类型更可读
- **record 不可变**:字段 final,不能写 setter,需要可变结构用普通类 + `@Data`(Lombok)
- **sealed 的穷尽检查**:新增子类后,所有 `switch` 模式匹配会编译报错提醒补分支,这是特性不是 bug
- **虚拟线程别用于 CPU 密集**:它解决的是 IO 并发,不是计算加速;且要配合池化、别用 `synchronized` 阻塞(会 pin 载体线程,Java 21 已有优化)
- **模式匹配要求 sealed 或有 default**:对非 sealed 类型用模式匹配 switch,必须加 default 兜底
