# 注解与反射

## 概述

> 注解(Annotation)是给代码附加元数据的标记;反射(Reflection)是在运行时动态获取类信息、操作成员的能力。二者结合是 Spring 等框架「自动装配」的底层基石——`@Autowired`、`@GetMapping` 能生效,全靠运行时反射读取注解。

## 核心知识点

### 常见内置注解

| 注解 | 作用 |
|------|------|
| `@Override` | 标记方法重写,编译期校验 |
| `@Deprecated` | 标记已废弃 |
| `@SuppressWarnings` | 压制编译警告 |
| `@FunctionalInterface` | 标记函数式接口 |

### 元注解(定义注解的注解)

```java
@Target(ElementType.METHOD)      // 能标在哪:方法/字段/类...
@Retention(RetentionPolicy.RUNTIME)  // 保留到何时:源码/编译/运行时
@Documented                      // 是否进 Javadoc
@Inherited                       // 子类是否继承
@Repeatable(...)                 // 能否重复标注
public @interface MyAnnotation {
    String value() default "";   // 注解元素,用法类似方法
    int level() default 1;
}
```

关键点:**`@Retention(RetentionPolicy.RUNTIME)` 才能被反射读取**,Spring 的绝大多数注解都是 RUNTIME 级别。

### 自定义注解

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface Log {
    String desc() default "";
}
```

### 反射基础

```java
// 1. 获取 Class 对象(三种方式)
Class<?> clazz = User.class;
Class<?> c2 = user.getClass();
Class<?> c3 = Class.forName("com.example.User");   // 需全限定名,抛 ClassNotFoundException

// 2. 构造实例
User u = (User) clazz.getDeclaredConstructor().newInstance();  // 新版,替代已废弃的 newInstance()

// 3. 操作字段
Field nameField = clazz.getDeclaredField("name");
nameField.setAccessible(true);          // 私有字段需放开访问权限
nameField.set(u, "张三");
String name = (String) nameField.get(u);

// 4. 调用方法
Method setName = clazz.getMethod("setName", String.class);
setName.invoke(u, "李四");

// 5. 读取注解
Method m = clazz.getMethod("someMethod");
Log log = m.getAnnotation(Log.class);
if (log != null) System.out.println(log.desc());
```

`getDeclaredXxx` 获取自身声明的(含私有),`getXxx` 获取继承的 public 成员。

## 示例

```java
// 用注解 + 反射实现一个简易的「字段非空校验器」
@Target(ElementType.FIELD)
@Retention(RetentionPolicy.RUNTIME)
@interface NotBlank {}

class User {
    @NotBlank String username;
}

public class Validator {
    static void validate(Object obj) throws IllegalAccessException {
        for (Field f : obj.getClass().getDeclaredFields()) {
            if (f.isAnnotationPresent(NotBlank.class)) {
                f.setAccessible(true);
                Object v = f.get(obj);
                if (v == null || v.toString().isBlank()) {
                    throw new IllegalArgumentException(f.getName() + " 不能为空");
                }
            }
        }
    }

    public static void main(String[] args) throws IllegalAccessException {
        User u = new User();
        validate(u);  // 抛异常:username 不能为空
    }
}
```

## 常见问题与坑

- **`newInstance()` 已废弃**:Java 9+ 用 `getDeclaredConstructor().newInstance()`
- **`Class.forName` 找不到类**:要传全限定名(带包名),且类在 classpath 里
- **私有成员直接访问报 `IllegalAccessException`**:忘了 `setAccessible(true)`(高版本模块系统下还可能因模块未开放而失败)
- **反射性能差**:反射调用比直接调用慢一个数量级,热点路径别滥用;框架一般会缓存 `Method`/`Field` 对象
- **注解没设 RUNTIME 保留期**:运行时读不到,`getAnnotation` 返回 null
- **getDeclaredField 找不到继承字段**:父类字段要用 `getSuperclass()` 递归找
