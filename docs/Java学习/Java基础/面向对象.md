# 面向对象

## 概述

> Java 的面向对象三大特性:封装、继承、多态,以及抽象类、接口、`static`/`final` 的用法。与 JS 最大的区别:Java 是**纯类式** OOP,没有原型链、没有鸭子类型,类是编译期就确定的结构。

## 核心知识点

### 类与对象

```java
public class Person {
    // 字段(成员变量),默认有隐式默认值
    private String name;   // private 封装,外部不可直接访问
    private int age;

    // 构造器:没有返回类型,名字与类相同
    public Person(String name, int age) {
        this.name = name;  // this 区分成员变量和形参
        this.age = age;
    }

    // getter / setter 控制访问
    public String getName() { return name; }
    public void setAge(int age) { this.age = age; }
}
```

`new Person("张三", 20)` 在堆上创建对象,栈上存引用。

### 继承

- Java **单继承**,一个类只能 `extends` 一个父类
- 子类构造器第一行默认调用 `super()`(父类无参构造),父类没有无参构造时必须显式 `super(args)`
- `@Override` 注解标记方法重写

```java
public class Student extends Person {
    private String school;
    public Student(String name, int age, String school) {
        super(name, age);   // 必须先调用父类构造
        this.school = school;
    }
    @Override
    public String getName() {
        return super.getName() + "(学生)";
    }
}
```

### 多态

父类引用指向子类对象,调用方法时**动态分派**到实际类型:

```java
Person p = new Student("李四", 18, "北大");
System.out.println(p.getName());   // 调的是 Student 重写后的方法
```

这是「依赖倒置 / 面向接口编程」的基石——方法签名用父类/接口,运行时传子类实现。

### 抽象类 vs 接口

| | 抽象类 abstract class | 接口 interface |
|---|---|---|
| 继承数量 | 单继承 | 可实现多个 |
| 字段 | 可有无 final 实例字段 | 只有常量(默认 `public static final`) |
| 方法 | 抽象 + 具体方法 | Java 8+ 可有 `default`/`static` 方法 |
| 语义 | 「是什么」,代码复用 | 「能做什么」,能力契约 |

```java
public interface Flyable {
    void fly();                       // 抽象方法
    default void land() { System.out.println("降落"); }  // 默认方法
}

public abstract class Animal {
    protected String name;
    public abstract void eat();       // 抽象方法,子类必须实现
    public void sleep() { System.out.println(name + " 睡觉"); }
}
```

### static 与 final

```java
public class MathUtil {
    public static final double PI = 3.14159;  // 常量:static + final
    private MathUtil() {}                     // 私有构造,防止实例化(工具类惯用法)

    public static int max(int a, int b) { return a > b ? a : b; }
}
// 调用:MathUtil.max(1, 2),无需 new
```

- `static`:属于类而非实例,全类共享一份
- `final`:类不能被继承 / 方法不能被重写 / 变量(字段、局部)赋值后不可变

### record(Java 16+,数据类)

只读数据载体,自动生成构造器、`equals`、`hashCode`、`toString`:

```java
public record Point(int x, int y) {}
Point p = new Point(1, 2);
System.out.println(p.x());   // 访问器是 x() 而非 getX()
```

## 示例

```java
public interface Shape {
    double area();
}

public class Circle implements Shape {
    private final double r;
    public Circle(double r) { this.r = r; }
    @Override public double area() { return Math.PI * r * r; }
}

public class Square implements Shape {
    private final double side;
    public Square(double side) { this.side = side; }
    @Override public double area() { return side * side; }
}

// 多态:同一段代码处理不同实现
List<Shape> shapes = List.of(new Circle(2), new Square(3));
for (Shape s : shapes) System.out.println(s.area());
```

## 常见问题与坑

- **`super()` 必须第一行**:子类构造器里 `super(...)` 只能是第一条语句
- **重写 ≠ 重载**:重写(override)是子类改父类方法;重载(overload)是同类同名不同参
- **字段没有多态**:字段访问是静态绑定的,`Person p = new Student()` 时 `p.name` 取的是 `Person` 的字段——只有**方法**才动态分派
- **接口变量隐式 final**:接口里写 `int x = 1` 实际是 `public static final int x = 1`
- **`equals` 没重写就用 `==` 语义**:自定义类想按内容比较必须重写 `equals` + `hashCode`(或直接用 record)
