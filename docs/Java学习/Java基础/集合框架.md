# 集合框架

## 概述

> Java 集合框架:`List`/`Set`/`Map` 三大体系、`ArrayList` 与 `LinkedList` 的选择、`HashMap` 原理、遍历与并发集合。集合是后端开发使用频率最高的数据结构,选对容器和避免并发修改异常是关键。

## 核心知识点

### 体系总览

```
Collection
├── List(有序、可重复):ArrayList、LinkedList、Vector
├── Set(无序、不重复):HashSet、LinkedHashSet、TreeSet
└── Queue/Deque:LinkedList、ArrayDeque、PriorityQueue
Map(键值对):HashMap、LinkedHashMap、TreeMap、ConcurrentHashMap
```

### List:ArrayList vs LinkedList

| | ArrayList | LinkedList |
|---|---|---|
| 底层 | 动态数组 | 双向链表 |
| 随机访问 get | O(1) | O(n) |
| 头尾增删 | 尾插 O(1),中间 O(n) | 两端 O(1) |
| 场景 | **绝大多数场景首选** | 频繁头插/实现队列 |

```java
List<String> list = new ArrayList<>();   // 面向接口编程
list.add("a");
list.get(0);
list.contains("a");
list.remove("a");
list.size();
List<String> immutable = List.of("a", "b", "c");  // Java 9+,不可变
```

### Set 与去重

`HashSet` 依赖元素的 `hashCode()` + `equals()` 判重,自定义类放进 Set 必须重写这两者(或用 record):

```java
Set<Integer> set = new HashSet<>();
set.add(1);
set.add(1);
System.out.println(set.size());   // 1,自动去重
```

`TreeSet` 按自然序/比较器排序,元素需实现 `Comparable`。

### Map 与 HashMap 原理

```java
Map<String, Integer> map = new HashMap<>();
map.put("a", 1);
map.get("a");              // 1
map.getOrDefault("b", 0);  // 0
map.containsKey("a");
map.remove("a");
map.putIfAbsent("a", 99);  // key 已存在则不覆盖
map.computeIfAbsent("k", k -> k.length());
for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + "=" + e.getValue());
}
```

**HashMap 要点**:基于数组 + 链表/红黑树,`put` 时先按 `hashCode` 定位桶,桶内 `equals` 比较;JDK 8 起单桶链表长度 > 8 且数组容量 > 64 时转红黑树;默认负载因子 0.75,扩容时容量翻倍。**key 应不可变**(常用 String/Integer/枚举)。

### 遍历与 fail-fast

增强 for 循环底层走迭代器,遍历时**结构修改**(增删)会抛 `ConcurrentModificationException`:

```java
// 错误:边遍历边删
for (String s : list) { if (s.equals("a")) list.remove(s); }  // 抛异常

// 正确:用迭代器删除
Iterator<String> it = list.iterator();
while (it.hasNext()) if (it.next().equals("a")) it.remove();

// 或 Java 8+ 的 removeIf
list.removeIf(s -> s.equals("a"));
```

### 并发集合

多线程共享集合时:普通集合不安全,要么加锁,要么用并发容器:

- `ConcurrentHashMap`:分段锁 + CAS,高并发首选
- `CopyOnWriteArrayList`:读多写少(写时复制)
- `Collections.synchronizedMap(map)`:简单包装,性能差于 ConcurrentHashMap

## 示例

```java
Map<String, List<String>> students = new HashMap<>();
students.computeIfAbsent("一班", k -> new ArrayList<>()).add("张三");
students.computeIfAbsent("一班", k -> new ArrayList<>()).add("李四");
students.computeIfAbsent("二班", k -> new ArrayList<>()).add("王五");

for (var e : students.entrySet()) {
    System.out.println(e.getKey() + ": " + String.join(",", e.getValue()));
}
// 一班: 张三,李四
// 二班: 王五
```

再加一个词频统计,练手 `Map` 的 `merge`:

```java
String text = "apple banana apple orange banana apple";
Map<String, Integer> freq = new HashMap<>();
for (String word : text.split(" ")) {
    freq.merge(word, 1, Integer::sum);   // 存在则 +1,不存在则置 1
}
freq.forEach((k, v) -> System.out.println(k + " -> " + v));
// apple -> 3, banana -> 2, orange -> 1
```

## 常见问题与坑

- **`Arrays.asList` 返回定长列表**:`add`/`remove` 会抛 `UnsupportedOperationException`;要可变用 `new ArrayList<>(Arrays.asList(...))`
- **HashMap 的 key 可变**:key 的 `hashCode` 变化会导致元素「丢失」,key 尽量用不可变类型
- **`List.of`/`Map.of` 不可变**:Java 9 的工厂方法产物不支持增删,也**不允许 null 元素**
- **边遍历边删**:牢记 `removeIf` 或迭代器
- **ArrayList 频繁头插**:性能差,改用 LinkedList 或 Deque
- **判空用 `Collections.emptyList()` 而非返回 null**:避免调用方 NPE
